# Board images (Work · "to be")

Drop any images here (jpg, png, webp, gif): film stills, tickets, posters, scenes, photos. They become photographs pinned on the Work board.
Optional real materials in `materials/`:
- `cork.jpg`   — a photo of a cork board (used as the background, tiled)
- `string.png` — a photo of red string/yarn, horizontal, cropped tight (used as the texture along every string)
- `pin.png`    — a cut-out pushpin on transparent background

Then run `python3 tools/board-manifest.py` (Claude does this) to refresh `js/board-manifest.js`.
